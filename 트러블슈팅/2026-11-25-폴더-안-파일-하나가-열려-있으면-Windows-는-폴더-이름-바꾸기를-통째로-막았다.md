# 2026-11-25 폴더 안 파일 하나가 열려 있으면, Windows 는 폴더 이름 바꾸기를 통째로 막았다

> 태그: #트러블슈팅 #Windows #파일잠금 #Node #키오스크

## 무엇을 / 왜

사진 키오스크는 화면 그림·프레임 같은 리소스를 PC 의 사진 폴더 아래 한 폴더에 받아 둡니다. 이 폴더 이름을 브랜드와 상관없는 이름 하나로 통일하기로 하고, 키오스크가 켜질 때 예전 폴더를 새 이름으로 옮기게 했습니다.

그런데 시험 PC 에서는 켤 때마다 이런 경고가 남고, 키오스크가 예전 폴더를 계속 쓰고 있었습니다.

```
EPERM: operation not permitted, rename '...\OldName\KR' -> '...\NewName\KR'  (5번 시도)
```

다른 프로그램이 잠깐 잡은 것이라 생각해, 짧게 몇 번 다시 시도하게 해 둔 상태였습니다. 그래도 다섯 번 모두 실패했습니다.

## 어떻게 풀었나

### 원인: 폴더는 막혀도 파일은 옮겨졌다

그 PC 에서 직접 시험해 보니, Windows 는 폴더 안 파일 하나라도 다른 프로그램이 열고 있으면 그 폴더 이름을 바꾸지 못했습니다. 지우기까지 허용하고 연 파일이어도 마찬가지였습니다. 그런데 열려 있는 바로 그 파일은 하나씩 이름을 바꿔 옮길 수 있었습니다.

누가 잡고 있는지도 코드로 따라가 봤습니다. 폴더를 옮기는 때는 부팅 중 리소스를 처음 찾을 때였고, 키오스크 창·카메라 서비스·장치 서비스를 띄우기 전이었습니다. 함께 도는 에이전트와 장치 서비스는 리소스 폴더를 열지 않았습니다. 그래서 잡은 쪽은 키오스크 밖의 검색 색인·백신 검사·사진 보기·탐색기 창 같은 것으로 좁혔습니다. 이런 프로그램은 언제 놓아줄지 알 수 없으니, 기다리는 것만으로는 풀리지 않았습니다.

### 고친 것: 막히면 파일 단위로

1. **표시 먼저:** 폴더 통째 옮기기가 끝내 막히면, 새 폴더 맨 위에 '옮기는 중' 표시 파일을 먼저 씁니다. 표시를 쓰지 못하면 예전처럼 예전 폴더를 그대로 씁니다.
2. **파일마다 옮기기:** 파일마다 이름을 바꿔 옮기고, 그래도 잡혀 있는 파일은 임시 이름으로 복사한 뒤 크기를 확인하고 수정 시각을 그대로 맞춰 둡니다.
3. **이번 실행은 새 폴더:** 새 폴더를 쓰고, 새 폴더에 아직 없는 파일만 예전 폴더에서 읽습니다.
4. **남은 것 정리:** 예전 폴더에 남은 파일은 새 폴더의 것과 같은 파일일 때만(크기와 시각, 다르면 내용) 나중에 지웁니다. 새 폴더 쪽이 더 새 것이면 덮지 않고 예전 판을 백업 폴더로 비켜 둡니다.
5. **끊겨도 이어서:** 전원이 꺼지거나 디스크 여유가 모자라거나 부팅 중 복사 시간이 길어지면 멈추고, 다음 부팅에 이어서 합니다. 같은 일을 두 번 해도 결과가 같게 만들었습니다.

## 코드로 보기 (개념 재현)

이름은 바꾼 더미입니다.

```js
const fs = require('node:fs');

// 다른 프로그램이 폴더 안 파일 하나를 열어 둔 상황
const fd = fs.openSync('C:/demo/old/KR/bg.png', 'r');

try {
  fs.renameSync('C:/demo/old/KR', 'C:/demo/new/KR');
} catch (e) {
  console.log(e.code); // EPERM  (폴더 통째는 막힘)
}

fs.mkdirSync('C:/demo/new/KR', { recursive: true });
fs.renameSync('C:/demo/old/KR/bg.png', 'C:/demo/new/KR/bg.png'); // 파일 하나는 옮겨짐
fs.closeSync(fd);
```

```js
// 막히면 파일 단위로 (흐름만)
function moveFolder(from, to) {
  try { fs.renameSync(from, to); return 'renamed'; }
  catch (e) { if (!['EPERM', 'EBUSY', 'EACCES'].includes(e.code)) throw e; }

  putMovingNote(to);                 // 새 폴더에 '옮기는 중' 표시
  for (const file of eachOldFile(from)) {
    if (!hasRoomOnDisk() || bootBudgetSpent()) return 'resume-next-boot';
    try { moveOne(file, to); }     // 이름 바꾸기
    catch { copyAndCheck(file, to); } // 잡혀 있으면 복사 + 크기 확인
  }
  return 'moved-by-file';          // 예전 쪽 남은 것은 같은 파일일 때만 나중에 지움
}
```

## 💡 배운 것

- Windows 에서는 "폴더 이름 바꾸기" 가 "안의 파일을 모두 옮기기" 보다 훨씬 쉽게 막힌다는 걸 배웠습니다. 폴더 통째 옮기기만 다시 시도하는 것으로는 남이 잡은 파일 하나를 이길 수 없었고, 막히는 단위를 파일로 작게 쪼개야 했습니다.
- 다른 프로그램이 잡고 있을 때는 누가 잡았는지 찾기 전에, 우리 쪽 프로그램이 범인이 아닌지부터 코드로 지워 나가니 범위가 빨리 좁혀졌습니다.
- 중간에 끊길 수 있는 옮기기는 '옮기는 중' 표시와 같은 파일인지 확인하는 정리를 함께 둬야, 다음에 이어 할 때 사진을 잃지 않는다는 걸 배웠습니다.
