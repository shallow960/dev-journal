# 2026-09-14 0.1초로 맞춘 간격이 1초로 들렸다

> 태그: #트러블슈팅 #음성합성 #오디오 #타이밍

## 무엇을 / 왜

대기 전광판에 뜬 호출번호를 **소리로도 부르기로** 했습니다. 문구는 "{호출번호} 탑승해주세요" 로 정해졌습니다.

번호는 "천이백삼십사" 가 아니라 **"일, 이, 삼, 사"** 로 또박또박 읽어야 해서 숫자 사이를 0.1초로 두기로 했습니다.

처음에는 브라우저에 내장된 음성 합성으로 만들었습니다. 그런데 **0.1초로 적어 둔 간격이 실제로는 1초쯤으로** 들렸습니다. 0.5초, 0.3초, 0.2초로 줄여 봐도 똑같았습니다.

## 어떻게 풀었나

### 숫자를 더 줄이지 않고, 왜 안 맞는지를 봤다

값을 바꿔도 결과가 같다는 건, 그 값이 결과를 정하고 있지 않다는 뜻이었습니다.

숫자 한 자리를 부르는 과정을 나눠 보니 이랬습니다.

```
[음성 만들기] → [재생] → [내가 정한 쉬는 시간 0.1초] → [다음 숫자 음성 만들기] → ...
      ↑                                                         ↑
   내가 정할 수 없는 시간                                  여기서 또 기다린다
```

브라우저 음성은 문장을 하나 넘길 때마다 **그 자리에서 소리를 만들어 받아옵니다.** 그 준비 시간이 제가 정한 쉬는 시간 위에 그대로 얹혔습니다. 제가 줄일 수 있는 건 0.1초 쪽뿐인데, 길게 들리는 건 다른 쪽이었습니다.

### 소리를 미리 만들어 두고, 재생만 했다

부를 소리는 정해져 있습니다. 숫자 0~9, 번호 없이 발권한 손님의 "T", 그리고 "탑승해주세요" 입니다.

이것들을 **mp3 조각으로 미리 만들어 두고** 화면은 이어서 재생만 하게 바꿨습니다. 재생에는 만드는 시간이 없으니 쉬는 시간을 제가 재면 그대로 나옵니다.

목소리는 제가 고르지 않고, 후보를 샘플 파일로 만들어 넘겨서 정해 받았습니다.

### 조각이 아예 안 울렸다

바꾸고 나니 이번엔 소리가 하나도 안 났습니다. 화면에는 오류가 없었습니다.

요청을 보니 조각 파일 주소가 **로그인 화면으로 넘겨지고** 있었습니다. 로그인하지 않은 요청을 로그인 화면으로 보내는 규칙이 새로 만든 소리 폴더까지 잡고 있었어요. 그 경로를 규칙에서 빼고 다시 올렸습니다.

### 소리는 덤으로 둔다

전광판의 본래 일은 화면에 번호를 띄우는 것입니다. 그래서 몇 가지를 지켰습니다.

- 조각 하나를 못 읽어도 다음 조각은 이어서 재생합니다
- 브라우저가 자동 재생을 막아도 화면은 그대로 돕니다
- 화면을 처음 열 때 이미 떠 있던 호출은 부르지 않습니다. 켤 때마다 밀린 손님을 전부 부르면 정작 지금 탈 손님이 묻힙니다
- 켜고 끄기, 부르는 횟수, 속도, 크기, 간격은 관리 화면에서 바꿉니다

## 코드로 보기 (개념 재현)

처음 방식입니다. 간격은 분명 100ms 인데 그렇게 들리지 않았습니다.

```js
function speak(text) {
  return new Promise((resolve) => {
    const u = new SpeechSynthesisUtterance(text);
    u.lang = "ko-KR";
    u.onend = resolve;
    // ★ speak() 를 부른 뒤 실제로 소리가 나기까지 걸리는 시간은 브라우저가 정한다.
    speechSynthesis.speak(u);
  });
}

async function callNumber(digits) {
  for (const d of digits) {
    await speak(d);
    await sleep(100);   // 이 값을 줄여도 체감 간격은 그대로였다
  }
  await speak("탑승해주세요");
}
```

미리 만든 조각을 이어서 재생하는 방식입니다.

```js
const CLIP_BASE = "/audio/call";

// "T1234" → ["t", "1", "2", "3", "4", "board"]
function clipsFor(label) {
  const m = String(label).match(/^([Tt]?)(\d{4})$/);
  if (!m) return [];                       // 부를 조각이 없는 표기는 화면에만 띄운다
  const names = [];
  if (m[1]) names.push("t");
  for (const d of m[2]) names.push(d);     // 자리마다 한 조각. 통째로 읽히지 않게.
  names.push("board");
  return names.map((n) => `${CLIP_BASE}/ko/${n}.mp3`);
}

const audio = new Audio();                 // 소리 낼 것은 하나. 조각을 갈아 끼운다.
const queue = [];
let playing = false;

function pump(setting) {
  if (playing) return;
  const next = queue.shift();
  if (!next) return;

  const wait = next.gap ?? setting.gap;    // 이제 이 값이 곧 들리는 간격이다
  const done = () => {
    if (!playing) return;
    playing = false;
    setTimeout(() => pump(setting), wait);
  };

  audio.onended = done;
  audio.onerror = done;                    // 조각 하나가 없어도 다음으로 넘어간다

  playing = true;
  audio.src = next.src;
  audio.playbackRate = setting.rate;
  audio.volume = setting.volume;
  // 자동 재생이 막히면 play() 가 거절된다. 화면은 계속 돌아야 하므로 삼킨다.
  audio.play().catch(done);
}

// 한 번 부르고 한 박자 쉰 뒤 다시 한 번
function announce(label, setting) {
  const clips = clipsFor(label);
  for (let turn = 0; turn < setting.repeat; turn++) {
    const again = turn < setting.repeat - 1;
    clips.forEach((src, i) => {
      const last = i === clips.length - 1;
      queue.push(last && again ? { src, gap: setting.repeatGap } : { src });
    });
  }
  pump(setting);
}
```

// 로그인 안 한 요청을 로그인 화면으로 보내는 규칙 (개념)
export const config = {

## 💡 배운 것

**값을 바꿔도 결과가 같으면, 그 값이 결과를 정하고 있지 않은 것입니다.** 간격을 0.5초에서 0.1초로 줄이는 동안 체감이 그대로였다면, 더 줄일 게 아니라 **내가 정할 수 없는 시간이 끼어 있는지**를 봐야 했습니다.

**실시간으로 만들기와 미리 만들어 두기는 쓰임이 다릅니다.** 문장이 매번 다르면 실시간 합성이 맞지만, 부를 소리가 열두 개로 정해져 있으면 미리 만들어 두는 쪽이 타이밍을 제 손에 쥐게 해 줍니다.

**오디오는 실패를 조용히 합니다.** 파일 대신 로그인 화면 HTML 이 와도 에러 화면이 뜨지 않습니다. 소리가 안 나면 네트워크 요청의 응답 코드와 내용을 먼저 보는 게 빨랐습니다.

**덤 기능은 실패해도 본 기능을 살려야 합니다.** 소리가 안 나는 것보다 전광판이 멈추는 게 훨씬 큰 문제입니다.

## 소감

"0.1초로 적었으니 0.1초겠지" 를 의심하는 데 시간이 좀 걸렸습니다. 숫자를 세 번 바꿔 보고서야 숫자가 문제가 아니라는 걸 받아들였어요.

결국 음성을 똑똑하게 만드는 게 아니라 **열두 개짜리 소리 조각 묶음**으로 풀렸습니다. 필요한 게 "말하기" 가 아니라 "정해진 소리를 정해진 간격으로 내기" 였다는 걸 늦게 알았습니다.
