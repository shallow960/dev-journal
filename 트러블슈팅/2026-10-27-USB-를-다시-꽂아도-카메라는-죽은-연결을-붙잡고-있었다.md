# 2026-10-27 USB 를 다시 꽂아도, 카메라는 죽은 연결을 붙잡고 있었다

> 태그: #트러블슈팅 #카메라 #USB #장치상태 #키오스크

## 무엇을 / 왜
사진 키오스크에서 카메라 USB 끊김을 시험해 보니, 선을 다시 꽂아도 카메라가 저절로 다시 붙지 않았습니다. 키오스크 화면에는 점검 화면이 떠 있었고, 매장 관리자가 관리 메뉴에서 카메라 제어 프로그램을 다시 켜야 풀렸습니다. 관리자가 늘 곁에 있지 않은 매장에서는 손님이 기다리다 돌아갈 수 있는 문제였습니다.

원인을 따라가 보니 이랬습니다.
- 카메라 제어 프로그램이 "카메라가 빠졌다"는 알림을 받지 않고 있어서, 선이 빠진 뒤에도 자기는 연결된 줄 알고 있었습니다.
- "카메라가 꽂혔다"는 알림은 받았지만, 기록만 남기고 아무것도 하지 않았습니다.
- 그래서 셔터를 누르면 이미 죽은 연결로 명령을 보내고, 기다린 끝에 실패했습니다.

## 어떻게 풀었나
- 카메라가 빠졌다는 알림을 받으면 '끊김'으로 표시하게 했습니다. 끊긴 동안 셔터를 누르면 기다리지 않고 바로 실패를 알리게 했습니다.
- 카메라가 꽂혔다는 알림이 오면 카메라와 새로 연결하게 했고, 연결되면 키오스크의 점검 화면이 관리자 조작 없이 풀리게 했습니다.
- 카메라 제어 프로그램이 예기치 않게 꺼지면 키오스크가 알아서 다시 띄우게 했습니다.
- 시험 키오스크에서 USB 를 다시 꽂으면 점검 화면이 저절로 풀리는 것을 확인했습니다.

## 코드로 보기 (개념 재현)
프로그램이 믿는 상태와 실제 연결을 따로 두고, 빠짐·꽂힘 알림을 쓰지 않을 때와 쓸 때를 흉내 냈습니다.

```js
// 카메라 연결 상태를 '빠짐/꽂힘' 알림으로 관리하는데, 고치기 전에는 알림을 제대로 쓰지 않았다 (개념 재현)
class CameraWatcher {
  constructor({ fixed }) {
    this.fixed = fixed
    this.connected = true                 // 프로그램이 믿는 상태
    this.session = { alive: true }        // 실제 카메라와 이어진 통로
  }
  usbRemoved() {
    this.session.alive = false            // 선을 뽑으면 실제 통로는 죽음
    if (!this.fixed) return '빠짐 알림을 받지 않음'
    this.connected = false
    return '끊김으로 표시'
  }
  usbAttached() {
    if (!this.fixed) return '로그만 남김'
    if (!this.connected) {                // 끊김으로 알고 있을 때만 새로 연결
      this.session = { alive: true }
      this.connected = true
      return '새로 연결함'
    }
    return '이미 연결됨'
  }
  shoot() {
    if (!this.connected) return '끊김 - 바로 실패를 알림'
    return this.session.alive ? '찍힘' : '실패 - 죽은 통로로 셔터를 보냄'
  }
}

for (const fixed of [false, true]) {
  const camera = new CameraWatcher({ fixed })
  const steps = [
    `USB 뺌: ${camera.usbRemoved()}`,
    `셔터: ${camera.shoot()}`,
    `USB 꽂음: ${camera.usbAttached()}`,
    `셔터: ${camera.shoot()}`,
  ]
  console.log(fixed ? '고친 뒤 ' : '고치기 전', steps.join(' / '))
}
```

실행 결과입니다.

```
고치기 전 USB 뺌: 빠짐 알림을 받지 않음 / 셔터: 실패 - 죽은 통로로 셔터를 보냄 / USB 꽂음: 로그만 남김 / 셔터: 실패 - 죽은 통로로 셔터를 보냄
고친 뒤  USB 뺌: 끊김으로 표시 / 셔터: 끊김 - 바로 실패를 알림 / USB 꽂음: 새로 연결함 / 셔터: 찍힘
```

고치기 전에는 USB 를 다시 꽂아도 셔터가 계속 죽은 연결로 갔고, 고친 뒤에는 다시 꽂자마자 찍혔습니다.

## 💡 배운 것
- 장치 연결을 '연결됨' 값 하나로 믿으면, 실제 연결이 죽어도 값은 그대로 남을 수 있다는 걸 배웠습니다. 빠짐 알림으로 값을 바꿔 주지 않으면 프로그램은 계속 연결된 줄 알았습니다.
- 꽂힘 알림을 기록만 하고 넘기면 스스로 복구할 기회를 버리는 셈이었습니다. 알림을 받았으면 상태를 바꾸고 다시 연결하는 데까지 이어야 했습니다.
- 끊긴 것을 알고 있다면 셔터를 기다리게 하지 말고 바로 실패를 알리는 편이 손님에게도 매장에도 나았습니다.

## 소감
예전 앱도 USB 를 다시 꽂으면 저절로 붙지 않았습니다. 예전 앱과 똑같이 옮기는 것이 목표였지만, 관리자가 없는 시간의 매장을 생각하면 이 부분은 예전보다 낫게 만드는 게 맞다고 생각했습니다.
