## 무엇을 / 왜

새로 받은 영문 동의 화면 그림을 키오스크에 넣어야 했습니다. 원본은 3241×5761 인데 화면이 쓰는 자리는 802×1255 였습니다.

비율이 달라서 그냥 늘이면 글자가 눌립니다. 그래서 **가운데를 잘라 비율을 맞추고** 줄였습니다.

화면으로 보기엔 괜찮아 보였습니다.

## 어떻게 풀었나

### 눈 대신 픽셀 값을 쟀다

넣기 전에 한국어판과 같은 조건인지 확인하려고 **모서리 픽셀 값**을 읽었습니다.

| 그림 | 모서리 픽셀 |
|---|---|
| 한국어판 | 완전 투명 (알파 0) |
| 영문판 (내가 만든 것) | 불투명한 검정 (알파 255) |

제가 자르면서 **투명도를 버리는 변환**을 걸었던 겁니다. 투명한 자리의 색 값은 원래 검정(0, 0, 0)으로 들어 있는데, 투명도가 사라지니 그 검정이 그대로 드러났습니다.

그대로 나갔으면 동의 창 둘레에 **검은 테두리**가 생겼을 겁니다.

### 되돌리다가 원본의 문제를 하나 더 찾았다

투명도를 살려 다시 만들면서 원본을 자세히 보니, 디자이너 그림에는 카드 뒤를 **어둡게 덮는 반투명 층이 이미 그려져** 있었습니다.

그런데 프로그램도 창을 띄울 때 뒤를 어둡게 덮습니다. 한국어판에는 그 층이 없었으니, 영문판만 **두 겹으로 어두워질** 상황이었습니다.

내 실수(투명도 손실)와 원본이 가진 문제(구워진 어둡게 덮기)는 따로 봐야 했습니다. 둘 다 걷어냈습니다.

### 가운데가 아니라 카드 테두리를 기준으로 잘랐다

한국어판과 겹쳐 보니 영문 카드가 틀 안에서 **작게 떠** 있었습니다. 원본 여백 비율이 달라서, 가운데 기준으로 자르면 카드 자리가 한국어판과 어긋났습니다.

이게 왜 문제냐면, 화면의 **닫기·동의 버튼을 누르는 자리는 코드에 좌표로** 정해져 있기 때문입니다. 그림 속 버튼과 누르는 자리가 어긋나면 손님이 버튼을 눌러도 반응이 없습니다.

카드 테두리를 찾아, 그 테두리가 한국어판과 **같은 좌표**에 오도록 다시 잘랐습니다.

### 여러 폴더를 대조로 마무리했다

같은 그림이 설치 방식별로 다섯 폴더에 흩어져 있었습니다. 바뀐 16장을 모두 넣은 뒤, 29종 × 한국어·영어 × 다섯 폴더가 **같은 파일인지 해시로 대조**했습니다.

## 코드로 보기 (개념 재현)

문제가 됐던 처리입니다.

```python
from PIL import Image

src = Image.open("consent_en_original.png")      # RGBA, 3241x5761
TARGET_W, TARGET_H = 802, 1255

# ★ 투명도를 버린다. 투명한 자리의 RGB(0,0,0)가 검정으로 드러난다.
img = src.convert("RGB")

# 가운데 기준으로 비율을 맞춰 자른다
w, h = img.size
new_h = int(w * TARGET_H / TARGET_W)
top = (h - new_h) // 2
img = img.crop((0, top, w, top + new_h)).resize((TARGET_W, TARGET_H), Image.LANCZOS)
img.save("consent_en.png")
```

넣기 전에 한 줄로 확인할 수 있었던 것입니다.

def corner(path):
    im = Image.open(path).convert("RGBA")
    return im.getpixel((0, 0))

print(corner("consent_ko.png")[3])   # 0    투명
print(corner("consent_en.png")[3])   # 255  불투명 → 다르다

고친 처리입니다. 투명도를 끝까지 들고 가고, 카드 테두리를 기준으로 자릅니다.

```python
import numpy as np
from PIL import Image

src = Image.open("consent_en_original.png").convert("RGBA")
a = np.asarray(src).copy()

# 1) 카드 영역 찾기: 거의 불투명한 픽셀이 모인 사각형
opaque = a[:, :, 3] > 240
ys, xs = np.where(opaque)
card = (xs.min(), ys.min(), xs.max() + 1, ys.max() + 1)

# 2) 원본에 구워진 "뒤를 어둡게 덮는 층" 걷어내기
#    카드 바깥은 모두 완전 투명으로. 어둡게 덮기는 프로그램이 한다.
mask = np.zeros(opaque.shape, dtype=bool)
mask[card[1]:card[3], card[0]:card[2]] = True
a[~mask, 3] = 0

img = Image.fromarray(a, "RGBA")

# 3) 카드가 한국어판과 같은 자리에 오도록 자른다
#    (KO_CARD: 한국어판에서 잰 카드 좌표, 화면 기준)
KO_CARD_LEFT, KO_CARD_TOP, KO_CARD_W = 60, 140, 682
scale = KO_CARD_W / (card[2] - card[0])
img = img.resize((round(img.width * scale), round(img.height * scale)), Image.LANCZOS)
left = round(card[0] * scale) - KO_CARD_LEFT
top  = round(card[1] * scale) - KO_CARD_TOP
img = img.crop((left, top, left + 802, top + 1255))

img.save("consent_en.png")   # RGBA 그대로 저장
```

## 💡 배운 것

**그림을 바꾼 뒤에는 눈이 아니라 픽셀 값으로 확인해야 합니다.** "괜찮아 보인다" 는 보는 바탕색에 따라 달라집니다. 모서리 픽셀 하나만 읽어도 차이가 숫자로 나왔습니다.

**형식 변환은 정보를 버릴 수 있습니다.** RGBA 를 RGB 로 바꾸는 한 줄이 투명도를 통째로 없앴습니다. 이미지를 다룰 때는 입력과 출력의 채널 수가 같은지부터 봐야 했습니다.

**내 실수와 원본의 문제는 갈라서 봐야 합니다.** 테두리는 제가 낸 것이고, 두 겹 어둡기는 원본이 가진 것이었습니다. 한쪽만 고쳤으면 "여전히 이상하다" 가 남았을 겁니다.

**누르는 자리와 맞춰야 하는 그림은 기준 테두리로 자릅니다.** 가운데 기준 자르기는 비율만 맞추고 위치는 보장하지 않습니다. 좌표가 코드에 박혀 있으면 그림 쪽이 그 좌표에 맞춰야 합니다.
