# 2026-11-10 Multi 를 눌렀는데, 시험 때 남긴 옛 유형이 그 자리를 차지하고 있었다

> 태그: #트러블슈팅 #키오스크 #시험데이터 #순서의존 #TypeScript

## 무엇을 / 왜

사진 키오스크에는 인화 방식을 고르는 "출력 스타일" 화면이 있습니다. 카드가 두 장 있었는데, 4Cut 은 한 장을 반으로 잘라 두 장을 주고 Multi 는 한 장을 그대로 주는 방식이었습니다. 카드를 고르면 그 방식에 맞는 프레임 목록으로 넘어가게 되어 있었습니다.

dev 시험 키오스크에서 Multi 카드를 골랐는데 4Cut 프레임이 나오는 문제가 있었습니다. 새 판을 막 올린 뒤라 처음에는 코드가 잘못 바뀐 줄 알았습니다.

## 어떻게 풀었나

먼저 화면이 카드와 데이터를 어떻게 잇는지 코드를 확인했습니다.

- 카드 그림은 고정이었습니다. 첫째 카드는 4Cut 그림, 둘째 카드는 Multi 그림입니다.
- 데이터는 테마에 들어 있는 "유형" 목록을 표시 순서대로 받아, 앞의 두 개를 카드 자리에 차례로 붙이고 있었습니다.

카드와 유형을 이름이 아니라 자리(순서)로 짝짓고 있었던 것입니다.

그다음 dev 데이터를 보니, 2026-10-23 시험 때 만든 옛 유형 하나가 표시 순서 맨 앞에 남아 있었습니다. 그래서 목록은 [옛 유형, 4Cut, Multi] 였고, 앞의 두 개를 자르니 [옛 유형, 4Cut] 이 되었습니다. 둘째 카드인 Multi 자리에 4Cut 유형이 붙어서, Multi 를 누르면 4Cut 프레임이 나왔습니다.

코드는 그대로 두고 옛 유형의 표시 순서만 뒤로 돌렸습니다. 그 뒤 시험 키오스크에서 4Cut 과 Multi 가 각각 제 프레임 목록을 보여 주었습니다.

## 코드로 보기 (개념 재현)

실제 이름은 바꾼 더미 코드입니다.

```ts
type Kind = { id: number; name: string; order: number };

// 카드 그림은 고정: 0번 자리 = 4Cut, 1번 자리 = Multi
const CARD_IMAGES = ['card-4cut.png', 'card-multi.png'];

// 문제가 된 방식: 표시 순서로 정렬한 뒤 앞의 두 개를 카드 자리에 그대로 붙인다
function pairByPosition(kinds: Kind[]) {
  const sorted = [...kinds].sort((a, b) => a.order - b.order);
  return sorted.slice(0, 2).map((kind, i) => ({ card: CARD_IMAGES[i], kind: kind.name }));
}

const devKinds: Kind[] = [
  { id: 1, name: '옛 시험 유형', order: 1 }, // 시험 때 만들고 지우지 않은 것
  { id: 2, name: '4Cut', order: 2 },
  { id: 3, name: 'Multi', order: 3 },
];

pairByPosition(devKinds);
// -> [ { card: 'card-4cut.png',  kind: '옛 시험 유형' },
//      { card: 'card-multi.png', kind: '4Cut' } ]   // Multi 카드 뒤에 4Cut 이 붙었다

// 이번에 한 일: 코드는 그대로 두고 옛 유형의 순서만 뒤로 돌렸다
devKinds[0].order = 9;
pairByPosition(devKinds);
// -> [ { card: 'card-4cut.png',  kind: '4Cut' },
//      { card: 'card-multi.png', kind: 'Multi' } ]
```

이번에는 데이터만 고쳤습니다. 데이터 하나가 앞에 끼어드는 것만으로 다시 밀릴 수 있는 구조라서, 카드마다 정해 둔 키로 유형을 찾는 쪽이 더 단단하다는 것도 알게 됐습니다. 아래는 그 방향만 보여 주는 개념 코드이고, 실제 화면에는 아직 넣지 않았습니다.

```ts
// 방향(개념): 카드마다 기대하는 키를 정해 두고, 그 키를 가진 유형만 붙인다
const CARDS = [
  { image: 'card-4cut.png', key: 'CUT_HALF' },
  { image: 'card-multi.png', key: 'WHOLE' },
];

function pairByKey(kinds: (Kind & { key?: string })[]) {
  // 키가 없거나 맞는 유형이 없으면 엉뚱한 것을 붙이지 않고 비워 둔다
  return CARDS.map((c) => ({ card: c.image, kind: kinds.find((k) => k.key === c.key)?.name ?? null }));
}
```
