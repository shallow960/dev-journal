# 2026-08-26 마이크가 없어서 카메라까지 안 열리던 문제

> 태그: #트러블슈팅 #브라우저미디어 #getUserMedia #폴백

## 무엇을 / 왜

브라우저 방송(WHIP)을 로컬에서 눌러 보는데 미리보기가 안 떴다. 뜨는 메시지는 이거.

```
카메라를 찾을 수 없어요. 카메라가 연결돼 있는지 확인해 주세요.
```

이상했다. 이 테스트 PC에 카메라는 분명히 붙어 있었으니까. 없다는 게 말이 안 됐다.

## 어떻게 풀었나

### 브라우저가 실제로 뭘 보는지 찍어 봤다

말로만 "있다/없다" 해 봐야 소용없어서, 브라우저가 인식하는 장치 목록을 직접 찍었다.

```
navigator.mediaDevices.enumerateDevices()
  .then(d => console.log(d.map(x => x.kind + ' : ' + x.label)))
```

결과:

```
videoinput  :
audiooutput :
```

라벨이 빈 건 권한 전이라 정상. 중요한 건 목록이었다. **videoinput(카메라)은 있는데
audioinput(마이크)이 아예 없다.** 스피커(audiooutput)만 있고 마이크가 없는 기기였음.

### 그럼 왜 카메라가 "없다" 고 나왔나

내 코드를 봤다.

```
getUserMedia({ video: {...}, audio: true })
```

카메라랑 마이크를 **한 번에** 요청하고 있었다. 그런데 마이크가 없으니 audio 제약을 못 채우고,
그러면 이 호출이 통째로 실패한다. 비디오는 멀쩡한데도. 실패 원인이 NotFoundError 로 오길래
내가 그걸 "카메라 없음" 으로 안내하고 있었던 거였다. 카메라 탓이 아니라 마이크 탓이었음.

### 고친 것

마이크가 없으면 영상만이라도 켜지게 폴백을 넣었다.

```
try {
  media = await getUserMedia({ video, audio: true });
} catch (e) {
  if (마이크문제(e)) {                       // NotFound / NotReadable ...
    media = await getUserMedia({ video, audio: false });  // 영상만
    안내("마이크를 찾지 못해 영상만 송출해요");
  } else throw e;
}
```

김에 오류 메시지도 원인별로 나눴다. 예전엔 무슨 일이 나든 "권한을 허용하세요" 한 줄이라
원인을 못 가렸다. 권한 차단 / 카메라 없음 / 다른 앱이 사용 중 / 보안 연결 아님을 각각
다르게 안내하게.

## 💡 배운 것

- **"카메라 없음" 이라고 안내했지만 진짜 원인은 마이크였다.** 하나로 묶어 요청하면 둘 중
  하나만 없어도 통째로 실패하고, 그러면 어느 쪽이 문제인지 사용자에게 거꾸로 알려주게 된다.
- 장치 문제는 추측하지 말고 enumerateDevices 로 찍자. 한 줄 찍으니 "마이크가 없다" 가
  바로 보였다.
- 오류 메시지 하나로 여러 원인을 뭉뚱그리면, 그게 그대로 오진 안내가 된다.

## 소감

이건 자동 테스트로는 절대 안 잡히는 종류였다. 마이크 없는 기기에서 실제로 눌러 봤으니까
나온 문제다. 화면 기능은 코드가 통과해도 실기기에서 눌러 봐야 안다는 걸 또 봤고, 그래서
이날부터 "로컬에서 눌러 보고 확인된 것만 배포에 묶는다" 로 방식을 바꿨다.
