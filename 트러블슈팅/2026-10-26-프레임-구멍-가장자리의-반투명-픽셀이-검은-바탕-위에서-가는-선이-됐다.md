# 2026-10-26 프레임 구멍 가장자리의 반투명 픽셀이, 검은 바탕 위에서 가는 선이 됐다

> 태그: #트러블슈팅 #이미지합성 #알파채널 #PNG #사진인쇄

## 무엇을 / 왜
사진 키오스크는 투명한 구멍이 뚫린 프레임 PNG 아래에 사진을 깔아 한 장으로 합성했습니다. 새 출력 형식(2인치 띠 두 줄)의 프레임을 등록하기 전에 미리 합성해 봤더니, 흰 테두리 프레임에서 왼쪽 띠 사진의 오른쪽 끝에 1~2픽셀짜리 어두운 세로선이 보였습니다. 사진 칸 좌표는 원래 앱의 값을 그대로 쓴 것이라 처음에는 어디가 틀렸는지 알 수 없었습니다.

## 어떻게 풀었나
- 그 자리의 픽셀을 하나씩 찍어 봤습니다. 사진 칸은 1135번 열에서 끝나는데, 프레임 그림의 구멍 가장자리는 1136번 열의 투명도 49, 1137번 열의 투명도 201로 반쯤 투명했습니다. 1138번 열부터는 완전히 불투명한 흰색이었습니다. 구멍 가장자리를 부드럽게 다듬으면서 생긴 반투명 픽셀이 사진 칸보다 2열 넓게 나와 있었던 것입니다.
- 합성은 검은 바탕 위에 사진을 칸 크기 그대로 붙이고 그 위에 프레임을 투명도만큼 덮는 방식이었습니다. 사진이 없는 1136·1137열에서는 검은 바탕이 반투명 흰색 밑으로 비쳐 밝기 49와 201로 남았고, 이것이 선으로 보였습니다.
- 원래 앱의 합성 코드도 확인해 봤습니다. 검은 바탕을 만들고, 사진을 칸 크기 그대로 복사하고, 프레임을 선형 알파로 덮는 방식이 똑같아서 원래 앱의 인쇄물에도 같은 선이 생긴다는 걸 알게 됐습니다.
- 원래 앱의 동작을 그대로 옮기는 것이 원칙이어서 좌표는 바꾸지 않았습니다. 선을 없애고 싶다면 사진 칸을 2열 넓혀 사진이 반투명 픽셀 밑까지 깔리게 하면 된다는 것을 확인해 두고, 실물 인쇄를 본 뒤에 정하기로 했습니다.

## 코드로 보기 (개념 재현)
가장자리 반투명 2열을 실제로 잰 투명도(49, 201)로 흉내 내고, 바탕색과 사진 너비를 바꿔 가며 합성해 봤습니다.

```js
// 사진 칸(0~9열)이 끝나는 자리 바로 오른쪽에, 프레임 구멍 가장자리가 반투명으로 2열 더 있다고 하자.
// 프레임 색은 흰색(255), 투명도는 실제 그림에서 잰 값(49, 201)을 쓴다.
const frameAlpha = [
  ...Array(10).fill(0),   // 0~9열: 구멍(완전 투명) - 여기는 사진이 보인다
  49, 201,                // 10~11열: 가장자리 반투명 - 사진 칸 밖
  255, 255,               // 12열~: 흰 테두리(불투명)
];
const PHOTO = 150;        // 사진 밝기(아무 값)

// 바탕(base) 위에 사진을 lastPhotoCol 열까지 붙이고, 그 위에 흰 프레임을 알파만큼 덮는다(선형 알파 합성).
function composite(base, lastPhotoCol) {
  return frameAlpha.map((alpha, x) => {
    const under = x <= lastPhotoCol ? PHOTO : base;  // 사진이 없는 곳은 바탕이 그대로 남는다
    const a = alpha / 255;
    return Math.round(255 * a + under * (1 - a));    // 흰색 * 알파 + 아래 * (1 - 알파)
  });
}
const show = (cols) => cols.slice(8).join(' ');       // 사진 끝 2열 + 가장자리 2열 + 테두리 2열만 본다
console.log('검은 바탕, 사진은 칸 크기 그대로:', show(composite(0, 9)));
console.log('흰 바탕,   사진은 칸 크기 그대로:', show(composite(255, 9)));
console.log('검은 바탕, 사진을 2열 넓힘     :', show(composite(0, 11)));
```

실행 결과입니다.

```
검은 바탕, 사진은 칸 크기 그대로: 150 150 49 201 255 255
흰 바탕,   사진은 칸 크기 그대로: 150 150 255 255 255 255
검은 바탕, 사진을 2열 넓힘     : 150 150 170 233 255 255
```

검은 바탕에서는 사진(150)과 흰 테두리(255) 사이에 더 어두운 49가 끼어 선이 됐습니다. 흰 바탕이었다면 보이지 않았고, 사진을 2열 넓히면 150 → 170 → 233 → 255로 자연스럽게 이어졌습니다.

## 💡 배운 것
- 투명 PNG 의 구멍은 "투명하거나 불투명하거나" 둘 중 하나가 아니라는 걸 배웠습니다. 가장자리를 부드럽게 만들면 반투명 픽셀이 생기고, 그 픽셀은 아래에 무엇이 깔려 있는지에 따라 다른 색이 됐습니다.
- 그래서 사진을 구멍 좌표에 딱 맞춰 붙일 때는, 구멍 가장자리의 반투명 픽셀이 사진 칸 밖으로 나와 있지 않은지 픽셀 단위로 확인해야 했습니다.
- 원래 앱과 다른 결과가 나왔다고 바로 고치기 전에, 원래 앱이 같은 방식으로 합성하는지부터 확인하는 편이 좋았습니다. 이번에는 원래 앱도 같은 선을 만들고 있었습니다.

## 소감
눈으로는 "테두리가 조금 진해 보인다" 정도였는데, 픽셀 값을 찍어 보니 원인이 숫자로 바로 드러났습니다. 실제 인쇄에서 이 선이 보일지는 프린터의 해상도와 번짐에 달려 있어서, 실물을 보고 마지막으로 정하기로 했습니다.
