# 2026-10-23 비싼 인화지 대신, 인쇄 이미지를 실제 용지 크기 PDF 로 받았다

> 태그: #새기술 #PDF #JPEG #Node #시험

## 무엇을 / 왜

사진 키오스크를 시험할 때 마지막 단계인 인쇄까지 확인해야 합니다. 그런데 사진 인화지가 비싸서, 시험할 때마다 실제로 뽑기는 부담스러웠습니다. 그래서 **시험 때는 프린터 대신 PDF 파일로** 받기로 했습니다.

Windows 기본 "PDF 로 인쇄" 프린터를 쓰면 될 것 같았지만, 인쇄할 때마다 "어디에 저장할까요?" 창이 떠서 사람 없이 도는 키오스크 흐름이 멈춥니다.

## 어떻게 풀었나

인쇄할 최종 이미지는 이미 JPEG 로 만들어져 있었습니다. 그리고 PDF 는 **JPEG 바이트를 바꾸지 않고 그대로 담을 수 있습니다**(PDF 의 `DCTDecode` 필터가 JPEG 를 뜻합니다). 그래서 작은 함수로 직접 PDF 를 만들었습니다.

1. JPEG 머리 부분(SOF 마커)에서 가로·세로 픽셀과 색 성분 수를 읽습니다.
2. 용지 크기를 PDF 단위인 포인트(1/72 inch)로 바꿉니다. 4x6 inch 용지는 288 x 432 포인트입니다.
3. 이미지가 가로면 용지도 가로로 돌립니다.
4. 페이지 1장(인쇄 매수만큼 여러 장도 가능)에 JPEG 를 꽉 채워 그립니다.
5. PDF 끝의 "각 객체가 파일 몇 바이트째에 있는지" 표(xref)를 정확히 적습니다.

시험 PC 에서만 켜지도록 환경변수가 있을 때만 이 경로를 탑니다. 이렇게 만든 PDF 를 PDF 라이브러리로 열어 보니 이렇게 나왔습니다.

```text
pages 1 size(pt) 288.0 432.0 images 1
```

1200 x 1800 픽셀 이미지가 4 x 6 inch 한 장에 들어갔고, 키오스크는 "인쇄 성공" 으로 다음 화면에 넘어갔습니다.

## 코드로 보기 (개념 재현)

```js
// jpeg-to-pdf.mjs - JPEG 한 장을 용지 크기 PDF 로 만든다 (개념 재현)
import { readFileSync, writeFileSync } from 'node:fs';

// JPEG 의 SOF 마커에서 크기를 읽는다. JPEG 가 아니면 멈춘다.
function readJpegSize(jpeg) {
  if (jpeg.readUInt16BE(0) !== 0xffd8) throw new Error('not a JPEG');
  let i = 2;
  while (i + 9 < jpeg.length) {
    if (jpeg[i] !== 0xff) { i++; continue; }
    const marker = jpeg[i + 1];
    if (marker === 0xff) { i++; continue; }                         // 채움 바이트
    if (marker === 0xd8 || (marker >= 0xd0 && marker <= 0xd7)) { i += 2; continue; } // 길이 없는 마커
    const isSOF = marker >= 0xc0 && marker <= 0xcf && ![0xc4, 0xc8, 0xcc].includes(marker);
    if (isSOF) {
      return { height: jpeg.readUInt16BE(i + 5), width: jpeg.readUInt16BE(i + 7), comps: jpeg[i + 9] };
    }
    i += 2 + jpeg.readUInt16BE(i + 2);                              // 다음 마커로 건너뛴다
  }
  throw new Error('no size marker');
}

// 용지는 마이크로미터로 받는다 (4x6 inch = 101600 x 152400)
function jpegToPdf(jpeg, paperUm = { width: 101600, height: 152400 }) {
  const { width, height, comps } = readJpegSize(jpeg);
  const toPt = (um) => Math.round((um / 25400) * 72 * 100) / 100;  // 1 inch = 25400um = 72pt
  let pageW = toPt(paperUm.width);
  let pageH = toPt(paperUm.height);
  if ((width > height) !== (pageW > pageH)) [pageW, pageH] = [pageH, pageW]; // 방향 맞추기
  const colorSpace = comps === 1 ? '/DeviceGray' : comps === 4 ? '/DeviceCMYK' : '/DeviceRGB';
  const draw = Buffer.from(`q ${pageW} 0 0 ${pageH} 0 0 cm /Im0 Do Q\n`); // 이미지를 페이지에 꽉 채운다

  const parts = []; const offsets = []; let size = 0;
  const push = (b) => { const buf = Buffer.isBuffer(b) ? b : Buffer.from(b, 'latin1'); parts.push(buf); size += buf.length; };
  const obj = (n, ...body) => { offsets[n] = size; push(`${n} 0 obj\n`); body.forEach(push); push('\nendobj\n'); };

  push('%PDF-1.4\n');
  obj(1, '<< /Type /Catalog /Pages 2 0 R >>');
  obj(2, '<< /Type /Pages /Kids [5 0 R] /Count 1 >>');
  obj(3, `<< /Type /XObject /Subtype /Image /Width ${width} /Height ${height} /ColorSpace ${colorSpace}`
        + ` /BitsPerComponent 8 /Filter /DCTDecode /Length ${jpeg.length} >>\nstream\n`, jpeg, '\nendstream');
  obj(4, `<< /Length ${draw.length} >>\nstream\n`, draw, 'endstream');
  obj(5, `<< /Type /Page /Parent 2 0 R /MediaBox [0 0 ${pageW} ${pageH}]`
        + ' /Resources << /XObject << /Im0 3 0 R >> >> /Contents 4 0 R >>');

  const xrefAt = size;                                               // 위치표가 시작하는 바이트
  push('xref\n0 6\n0000000000 65535 f \n');
  for (let n = 1; n <= 5; n++) push(`${String(offsets[n]).padStart(10, '0')} 00000 n \n`); // 각 객체의 바이트 위치
  push(`trailer\n<< /Size 6 /Root 1 0 R >>\nstartxref\n${xrefAt}\n%%EOF\n`);
  return Buffer.concat(parts);
}

writeFileSync('print.pdf', jpegToPdf(readFileSync('print.jpg')));
```

## 💡 배운 것

- PDF 는 "객체 목록 + 각 객체의 바이트 위치표(xref)" 로 된 단순한 구조라서, JPEG 한 장짜리 PDF 는 라이브러리 없이 직접 만들 수 있다는 걸 배웠습니다.
- JPEG 는 PDF 안에 다시 압축하지 않고 그대로 넣을 수 있어서, 화질이 그대로이고 만드는 것도 빠릅니다.
- 위치표의 숫자가 한 바이트만 틀려도 깨진 파일이 될 수 있어서, 시험에서 "위치표의 각 숫자가 정말 그 객체의 시작을 가리키는지" 를 직접 확인했습니다.

## 소감

인쇄 시험 때문에 인화지를 쓰지 않아도 되니 마음 편히 여러 번 돌려 볼 수 있게 됐습니다. 파일 형식을 직접 만들어 보니, 평소 그냥 열어 보던 PDF 가 조금 친숙해졌습니다.
